# Hand-Dryers

**Smart Automatic Hand Dryers — Commercial Hygiene Solutions (Nature Hygiene)**

A modern, responsive single-page product showcase website exclusively dedicated to commercial automatic hand dryers, built with HTML5, CSS3, Bootstrap 5.3.3, JavaScript, and jQuery.

## Key Features
- 3-column studio showcase with daily usage tiers (`0-100`, `100-500`, `Above 500` usage per day)
- Category filtering & live product search
- Technical specifications modal & direct quote request workflow
- Interactive Paper Towel vs. Automatic Hand Dryer ROI savings calculator
- Responsive gallery lightbox, FAQ accordion, WhatsApp direct chat, and form validation

## Project Structure
- `index.html` — Main landing page
- `style.css` — Custom styling and responsive layout
- `script.js` — Product catalog, filtering, modal specs, ROI calculator, and form validation
- `images/` — Brand logo and product imagery
